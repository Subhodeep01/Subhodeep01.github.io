Suppose every item in a collection belongs to two groups. We want to select some items, while giving every group at least a minimum number of contributions and no more than a maximum. Our main goal is to find a set PPP that is fair and has maximum cardinality.

There may be many equally large fair sets. We choose among them using a modular proxy: assign each element a fixed weight equal to its value on its own, then add those weights. Our chosen PPP has the greatest proxy weight among the maximum-cardinality fair sets. Fairness and size come first; proxy weight breaks ties between sets of that size.

The trick is to change the question. A sequence of graph constructions turns these fairness constraints into a perfect matching problem. Each construction preserves the solutions and their weights, so a matching algorithm can do the optimization for us.

This article develops the complete argument for computing PPP in Problem 2. We will keep the proofs alongside the intuition, including the parity correction, self-pairs, arbitrary real weights, and the operation count.

Lemma 1 · Computing P exactly

A maximum-weight fair set among those of maximum size NNN can be computed in O(∣G∣+n3)O(|G|+n^3)O(∣G∣+n3) arithmetic operations, or the algorithm reports that no fair set exists. The operation count is independent of the magnitudes of the lower and upper bounds. With we=0w_e=0we​=0 for every element, the same algorithm returns a fair set of size NNN, with no preference among sets of that size.

What the modular proxy measures

Let fff denote the original monotone submodular set-value objective, normalized so that f(∅)=0f(\varnothing)=0f(∅)=0. We assign the fixed singleton weights

The proxy www is modular: an element's contribution does not depend on which other elements have been selected. We optimize this proxy among fair sets of size NNN; we do not assume that the original fff is modular. The chosen PPP is therefore not guaranteed to maximize f(P)f(P)f(P).

For example, two movies may each cover many viewers, but share most of those viewers. The proxy adds both singleton audience counts; the coverage objective counts their union. More generally, normalization and submodularity give f(S)≤w(S)f(S)\le w(S)f(S)≤w(S), with equality possible when there is no loss from diminishing returns.

Additivity is what lets the matching construction preserve the optimization objective exactly. The singleton proxy is a heuristic for choosing a promising PPP among equally large fair sets; it is not required to make PPP fair or maximum-cardinality. If the original objective is itself modular, the proxy agrees with it. The lemma and its proof allow arbitrary real weights; singleton values are our chosen application. Computing them takes nnn value-oracle evaluations, separate from the arithmetic-operation bound for the given-weight algorithm.

Each external node belongs to one end of one edge. A loop in H1H_1H1​ therefore becomes a twin edge between two distinct external nodes, never a loop in H2H_2H2​. A twin edge between two plain nodes is a dummy-clique edge or a zzz-to-dummy edge, and H1H_1H1​ has at most one such edge per pair.

Twin edges involving external nodes cannot be parallel, since an external node belongs to only one twin edge. Filler edges join distinct internal–external pairs, once per pair. They cannot duplicate a twin edge, because twin edges have no internal endpoints. Thus H2H_2H2​ is simple.

The constructions now give one complete algorithm for the stated objective: find a fair set of maximum cardinality, then maximize its additive weight among sets of that size. Two bonuses enforce two different priorities.
