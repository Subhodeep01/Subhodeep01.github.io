How do you find a valuable selection without breaking fairness? Start from a fair set and make exchanges toward a high-value reference. Then ask a separate question: can we prove the answer is good?

The walk does not aim for the unknown optimum. Its first target is Y0Y_0Y0​, a greedy set that respects upper bounds and may miss lower bounds. The optimum is a comparison set in the proof. A certificate can establish the desired value guarantee immediately; a fallback search supplies a worst-case guarantee if the certificate does not pass.

The promise · Theorem CH

For 0<ε≤1/40<\varepsilon\le 1/40<ε≤1/4, the output is upper-fair, has total shortfall at most εN\varepsilon NεN, and has value at least (1/2−ε)OPT(1/2-\varepsilon)\mathrm{OPT}(1/2−ε)OPT. A certificate obtained during the fair route search proves the same value bound with exact fairness. The fallback may allow shortfall; an accepted restoration recovers exact fairness.

I · The objects we work with

There are n=∣V∣n=|V|n=∣V∣ available elements. Each has two group slots, one at each endpoint of its edge. In Problem 1 the endpoints come from two separate attributes. In Problem 2 they come from the same pool of groups, so an element may be a self-loop. Both of a loop's slots count at its one group.

For a selection SSS, deg⁡S(v)\deg_S(v)degS​(v) counts its slots at group vvv. The group has lower bound ℓv\ell_vℓv​ and upper bound uvu_vuv​. A set is upper-fair if it respects all upper bounds, and fair if it respects both bounds. Define the total lower-bound shortfall by

fav⁡(S)=∑vmax⁡(0,ℓv−deg⁡S(v)).\operatorname{fav}(S)=\sum_v\max(0,\ell_v-\deg_S(v)).fav(S)=v∑​max(0,ℓv​−degS​(v)).

An upper-fair set is fair exactly when its shortfall is zero. Lowercase nnn counts all available elements; uppercase NNN is the size of a largest fair set.

The value function fff is normalized, monotone and submodular: f(∅)=0f(\varnothing)=0f(∅)=0, adding elements never hurts, and the same addition gives no greater gain on a larger base set. Write f(A∣T)=f(T∪A)−f(T)f(A\mid T)=f(T\cup A)-f(T)f(A∣T)=f(T∪A)−f(T), with f(e∣T)f(e\mid T)f(e∣T) for a singleton. Let OOO be an optimal fair set and OPT=f(O)\mathrm{OPT}=f(O)OPT=f(O) its value. We assume a fair set exists.

The workhorse. Given a fixed number w(e)w(e)w(e) for each element, we can exactly maximize ∑e∈Sw(e)\sum_{e\in S}w(e)∑e∈S​w(e) over fair sets: by min-cost flow for Problem 1, or weighted matching for Problem 2. Our companion article on matching shows how the shared-group reduction works and how to prioritize cardinality when computing PPP. A certificate call, by contrast, maximizes its supplied weights over all fair sets.

II · The method at a glance

  1. Build fair starting points and the greedy reference Y0Y_0Y0​.
  2. Walk toward Y0Y_0Y0​ while preserving fairness and increasing value. Keep the best result T1T_1T1​.
  3. Compute an upper bound UUU on OPT\mathrm{OPT}OPT. If f(T1)≥(1/2−ε)Uf(T_1)\ge (1/2-\varepsilon)Uf(T1​)≥(1/2−ε)U, return T1T_1T1​.
  4. If needed, use the certificate's maximizing set as another target and try again.
  5. If no certificate passes, run the fallback local search.
  6. Optionally restore exact fairness and continue improving, subject to the acceptance checks below.

III · Build the starting sets

PPP, a largest fair set. Find a fair set of size NNN, breaking ties by the sum of singleton values f({e})f(\{e\})f({e}). Use the flow or matching route appropriate to the problem. Those singleton weights are a proxy; the algorithm does not need PPP to maximize the submodular objective. Its cardinality gives NNN, which sets the fallback's shortfall budget.

Y0Y_0Y0​, the greedy reference. Start empty and repeatedly add the element with greatest current marginal gain that fits under every upper bound. Stop when no element fits. The lower bounds do not constrain this step, so Y0Y_0Y0​ can have a shortfall.

QQQ, the fair projection of Y0Y_0Y0​. Replay the greedy additions and record the gain g(e)g(e)g(e) when each element enters. The recorded gains telescope to f(Y0)f(Y_0)f(Y0​). Give each element inside Y0Y_0Y0​ weight g(e)g(e)g(e), and each element outside it weight f(e∣Y0)f(e\mid Y_0)f(e∣Y0​). Optimize these fixed weights over fair sets. This is a projection by a modular score; it need not be the closest set under any particular distance. Polish the result with value-increasing single additions and one-for-one swaps. A move must respect all upper bounds and leave each group with at least the smaller of its current degree and its lower bound. From a fair start this preserves exact fairness.

LLL, an optional LP start. For coverage and facility objectives, solve the linear programming relaxation, which gives fractional element values xe∈[0,1]x_e\in[0,1]xe​∈[0,1]. Find a maximum-weight fair set using those values as weights, breaking ties toward valuable elements, and polish it by the same rule. QQQ and LLL are both fair.

IV · Walk along alternating trails

Take a current fair set TTT and a reference RRR, initially Y0Y_0Y0​. Keep the shared elements in place. Color T∖RT\setminus RT∖R green (remove) and R∖TR\setminus TR∖T rust (add). At each group, pair as many opposite-color slots as possible, each slot at most once. Follow the pairings through the elements. The resulting trails alternate colors; they stop at unpaired slots or close into cycles.

A trail or contiguous piece gives a candidate move: remove its TTT-colored elements and add its RRR-colored elements. Opposite-color slots cancel in the middle. Only the endpoint slots can change a degree, so we can check the bounds using their net changes. This works with self-loops because pairing is defined on slots, including both slots of a loop.

Short pieces. Number the RRR-colored elements along a trail. For a cut level qqq, copy the trail qqq times and in copy iii delete the RRR-elements labeled i mod qi\bmod qimodq. The remaining stretches are shorter alternating pieces. The route search considers whole trails as well as pieces (the supplied recipe uses cut levels 2, 4, and 8).

Which move wins? Among the candidates, keep only those respecting the upper bounds and preserving zero shortfall. Take the best value gain if it exceeds γH=εMall/n\gamma_H=\varepsilon M_{\rm all}/nγH​=εMall​/n, where Mall=max⁡ef({e})M_{\rm all}=\max_e f(\{e\})Mall​=maxe​f({e}). Then rebuild trails from the updated set. When no candidate qualifies, stop. If Mall=0M_{\rm all}=0Mall​=0, normalization and submodularity give no positive gain; otherwise f(T)≤nMallf(T)\le nM_{\rm all}f(T)≤nMall​ bounds the number of accepted moves by n2/εn^2/\varepsilonn2/ε. Compute and test. For fixed TTT, give elements outside TTT the weight f(e∣T)f(e\mid T)f(e∣T) and elements inside weight zero. A failed test means only that this bound did not certify the answer.

Tighten the bound. Take the minimum of valid upper bounds: f(V)f(V)f(V) by monotonicity, the LP value when available, Lemma C1 applied at other base sets (a chain can start at TTT and grow to T∪S∗T\cup S^*T∪S∗), and a cut bound from multiple submodular upper inequalities. The cut solver can stop at a time budget; use its proven upper bound, not the value of the best feasible solution it found.

VI · Use a failed certificate to guide another walk

The maximizing fair set S∗S^*S∗ points to elements with high total marginal weight at TTT. Add it to the references and continue walking from the current fair set toward the reference sets. Recompute the certificate. The method uses a small round budget (three by default), returning as soon as the test passes.

Accepted walk moves only increase value, but a newly computed bound need not decrease. Keeping Umin⁡U_{\min}Umin​, the smallest valid bound found anywhere during the run, lets us reuse every improvement in the certificate.

Proof · How the unknown optimum enters the argument

1. Build comparison pieces. At a terminal set TTT, form alternating trails between TTT and the unknown fair optimum OOO. There is at least twice as much negative mass as positive mass. Each positive piece costs one or two units, and each reducing piece pays one or two. The grouping lemma ensures these disjoint bundles fit the move bounds and do not increase shortfall. Since bundling partitions the pieces, the appearance counts from step 1 survive.

VIII · Restore and improve

Restore exact fairness if needed. Try shortfall-reducing walks and re-optimize between repairs. The implementation may use a fair projection if the repair search does not finish within its budget. Accept an exactly fair candidate FFF only if f(F)≥(1/2−ε)Umin⁡f(F)\ge(1/2-\varepsilon)U_{\min}f(F)≥(1/2−ε)Umin​ and f(F)≥f(T1)f(F)\ge f(T_1)f(F)≥f(T1​). If this check fails, keep the fallback result with its existing guarantee.

Optional improvement. Use remaining time to seek value-increasing exchanges that respect the upper bounds and never increase shortfall. This preserves the guarantees already established.
